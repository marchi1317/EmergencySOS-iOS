# 🚨 EmergencySOS iOS

## معرفی پروژه

EmergencySOS یک برنامه کمک اضطراری برای آیفون است که با زبان Swift و رابط کاربری SwiftUI توسعه یافته است.

هدف برنامه، آماده‌سازی پیام اضطراری همراه با موقعیت مکانی و تسهیل تماس با مخاطبان تعیین‌شده است.

## امکانات برنامه

- رابط کاربری فارسی
- ذخیره سه شماره تماس اضطراری
- شمارش معکوس ۳۰ ثانیه‌ای
- امکان لغو عملیات اضطراری
- دریافت موقعیت مکانی و ایجاد لینک نقشه
- آماده‌سازی پیامک اضطراری برای مخاطبان
- شروع فرایند تماس با مخاطب اول پس از ارسال موفق پیام اضطراری
- امکان ارسال پیام و برقراری تماس دستی

## مشخصات فنی

- زبان برنامه‌نویسی: Swift 6
- رابط کاربری: SwiftUI
- حداقل نسخه سیستم‌عامل: iOS 16
- محیط توسعه: Xcode
- ساخت پروژه: XcodeGen
- آزمایش کامپایل: GitHub Actions

## وضعیت ساخت

پروژه با موفقیت برای دو مقصد زیر کامپایل شده است:

- iOS Simulator
- iPhone Device، بدون امضای دیجیتال

این موفقیت به معنی آزمایش عملکرد برنامه روی آیفون واقعی نیست.

## محدودیت‌های iOS

به دلیل محدودیت‌های امنیتی سیستم‌عامل iOS:

- ارسال پیامک به تأیید کاربر نیاز دارد.
- برقراری تماس تلفنی تحت کنترل سیستم‌عامل است.
- پایان خودکار تماس پس از مدت مشخص تضمین نمی‌شود.
- عملکرد پیامک، تماس و GPS باید روی آیفون واقعی آزمایش شود.
